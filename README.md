# RenameBuildings

A Kenshi mod that lets you rename most player-owned buildings.
That includes workstations, which was the intended purpose of this mod. As a bonus, it also works for other buildings you own, as long as they have no doors.

Get it from your preferred modding platform:
- **Steam Workshop**: [RenameBuildings](https://steamcommunity.com/sharedfiles/filedetails/?id=3759303115)
- **NexusMods**: [RenameBuildings](https://www.nexusmods.com/kenshi/mods/2031)

## Features

- **Selection-aware, movable button** - A small "Rename" button appears on the left side of the screen when a player-owned building is selected. It hides automatically when nothing is selected or when the selected building is not yours. The button can be repositioned by dragging it to any location on the screen. The button stays clamped to screen edges so it cannot be moved off-screen.
- **Rename window** - Click the "Rename" button to open a compact window pre-filled with the current building name. Edit the name and click "Rename" to confirm, or click the X button to cancel.
- **Ownership check** - Only buildings owned by the player can be renamed.
- **Persistent through saves** - Renamed buildings keep their new name when saving and loading.
